TradFR - proposer une traduction

Toutes les lignes de texte d'ARK: Survival Ascended, avec leur traduction actuelle. Corrigez ce qui vous gene, proposez ce qui manque.

Comment ca marche

Cherchez une ligne, modifiez le francais, puis cliquez sur Proposer en bas. GitHub s'ouvre avec votre contribution deja ecrite : il ne reste qu'a confirmer. Un fork, une branche et une pull request sont crees automatiquement.

Il faut un compte GitHub, gratuit. Vous n'avez rien a installer et vous ne pouvez rien casser : chaque proposition est verifiee automatiquement, puis relue avant d'etre integree.

Quelques reperes pour traduire :

  • Les noms d'objets et de creatures suivent ARK: Survival Evolved : Smilodon, Croquette, Argile, Dino-Porte.
  • Les variables entre accolades comme {0}, %s ou <RichColor> doivent etre reprises telles quelles, sinon le texte s'affiche tronque en jeu.
  • Gardez les espaces de debut et de fin a l'identique : le jeu colle souvent plusieurs morceaux bout a bout.
  • Espace insecable avant ! ? : ; et pas de tiret cadratin, on ecrit un tiret simple.
